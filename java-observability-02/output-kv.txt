# 既定のログの形式(Spring Boot)で、貸出を記録したとき
INFO --- [o-auto-1-exec-1] example.books.BookService                : 本を登録した id=3 copies=4
INFO --- [o-auto-1-exec-2] example.books.BookService                : 貸し出した
