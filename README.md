# code-to-design-sample

技術ブログ「Code to Design」の記事で使っているコードと、実行結果（計測の生データ）を、記事ごとに置いたリポジトリです。

記事のコードは、ここにあるファイルをそのまま載せています。記事の中で「`data/` にある」と書かれているファイルは、このリポジトリの、記事のIDと同じ名前のディレクトリにあります。

```text
code-to-design-sample/
├── environment*.txt       計測した環境(シリーズごと)
└── <記事id>/
    ├── src/*.java         実験に使ったプログラム(Mavenのプロジェクトでは pom.xml と src/)
    ├── *.csv / *.txt      実行結果や計測結果(jcmd、GCログ、コマンドの出力を含む)
    └── charts.ts          計測結果から図を作るスクリプト(記事のサイトのリポジトリで使うもの)
```

## 動かし方

- Javaのコードは、記事ごとに、先頭のコメント(`// 実行: ...`)に書かれたコマンドで動かします。JDK 21(Eclipse Temurin)で確かめています。
- Mavenのプロジェクトは、Maven 3.9.16で確かめています。
- C++のコードは、g++(GCC 13)で、`-std=c++20` を付けて確かめています。
- データベースを使う記事は、PostgreSQL 18とMySQL 8.4が必要です。接続の情報は、環境変数で渡します。
- 計測値は、環境(CPU、ディスク、OS)で変わります。記事の数値は、各ディレクトリの結果と一致させています。計測には、`javac` でコンパイルしてから `java -cp` で実行する方法を使っています。

## このリポジトリについて

このリポジトリは、記事の原稿を管理する非公開のリポジトリの `data/` ディレクトリを、自動で写したものです。ここで直接変更しても、次の更新で上書きされます。誤りや質問は、Issueでお知らせください。
