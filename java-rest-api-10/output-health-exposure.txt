# 内訳を含めない設定(show-details: never)
$ curl http://localhost:PORT/actuator/health
-> 200  {"groups":["liveness","readiness"],"status":"UP"}
$ curl -u admin:(パスワード) http://localhost:PORT/actuator/env   (公開していないエンドポイント)
-> 403  {"detail":"必要な権限がありません。","instance":"/actuator/env","status":403,"title":"この操作は許可されていません","type":"https://api.example.com/problems/forbidden"}
