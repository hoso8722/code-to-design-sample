## A. server.shutdown=graceful(設定ファイルのとおり)。4秒かかる要求を送り、1秒後に停止を指示
1010 ms: 停止の指示(SIGTERM)を送る
1540 ms: 停止の指示のあとに送った新しい要求 -> 000(000は接続できなかった)
4230 ms: 処理中の要求の結果 -> HTTP 200  curlの終了コード=0(要求は 4秒かかる処理。結果が出た時刻は 4220 ms)
4520 ms: アプリケーションが終了
    ログ: o.s.boot.tomcat.GracefulShutdown         : Commencing graceful shutdown. Waiting for active requests to complete
    ログ: o.s.boot.tomcat.GracefulShutdown         : Graceful shutdown complete

1020 ms: 停止の指示(SIGTERM)を送る
