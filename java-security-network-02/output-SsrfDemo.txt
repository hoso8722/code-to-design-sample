## 2. 検査なし: 利用者のURLをそのまま取得
  内部のURL                         取得 内部の管理用トークン: internal-token
## 3. スキームとアドレスの検査
  内部のURL                         拒否 SecurityException: 内部のアドレス: 127.0.0.1 -> 127.0.0.1
  file スキーム                      拒否 SecurityException: 許可しないスキーム: file
  公開のURL                         取得 公開のページ
## 4. リダイレクト(公開のURLが、内部のURLへ転送する)
  最初のURLだけ検査                     取得 内部の管理用トークン: internal-token
  転送先ごとに検査                       拒否 SecurityException: 内部のアドレス: 127.0.0.1 -> 127.0.0.1
  転送先ごとに検査(公開のURL)               取得 公開のページ
