## 1. スレッドセーフでないオブジェクトを共有する(8スレッド × 20000 回)
  SimpleDateFormat を共有                   160000 回のうち、結果が違った回数 120340、例外 19570
  SimpleDateFormat をスレッドごとに持つ            160000 回のうち、結果が違った回数 0、例外 0
  DateTimeFormatter(不変)を共有               160000 回のうち、結果が違った回数 0、例外 0
## 2. スレッドプールで ThreadLocal を使う
  片付けなし: 別のタスクが読んだ CURRENT_USER = alice
  remove() あり: 別のタスクが読んだ CURRENT_USER = null
## 3. 範囲を閉じる関数と、InheritableThreadLocal
  runWithUser の中: alice
  同じスレッドの、runWithUser の外: null
  例外で抜けた後の、同じスレッド: null
  親が alice を設定し、プールのスレッドが作られたとき: alice
  親が bob に変えたあと、同じプールのスレッドが読んだ値: alice
  親が bob に変えたあとに作った新しいスレッドが読んだ値: bob
## 4. データを共有変数で渡す場合と、キューで渡す場合
  共有変数(volatile)で渡す: 1000000 個のうち受け取れた個数 75868
  BlockingQueue で渡す      : 1000000 個のうち受け取れた個数 1000000、順番が違った個数 0
